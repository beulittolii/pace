# PACE 자동 로그인 대기 화면

페이지를 열 때 자동 로그인이 진행 중인지 알 수 있게 하고, 자동 로그인과 수동 로그인이 겹치지 않게 한다.

- 저장된 세션을 확인하는 동안 `로그인 상태 확인 중…`을 표시한다.
- 저장된 세션이 확인되면 `자동 로그인 중…`으로 바꾸고, 권한 확인과 학습 데이터 로드가 끝날 때까지 유지한다.
- 두 단계 모두 아이디, 비밀번호, 비밀번호 표시 버튼, 자동 로그인 체크박스, 로그인 버튼을 비활성화한다. 회원가입 버튼도 초기 인증 확인이 끝난 후 활성화해 화면 전환 충돌을 막는다.
- 저장된 세션이 없거나 복구가 실패하면 수동 로그인으로 돌아간다. 실패 시 기존 오류 안내를 표시한다. 성공 시 기존 대시보드나 초대 코드 화면으로 이동한다.
- 수동 로그인 버튼의 `로그인 중…` 표시와 Firebase 세션 저장 방식은 유지한다. 새 의존성을 추가하지 않는다.

## 접근 방식

로그인 버튼에만 문구를 표시하면 기존 전체 화면 로딩 화면이 버튼을 가린다. 별도 화면을 추가하는 대신 기존 로딩 화면에 상태 문구를 표시하고 로그인 컨트롤을 함께 잠근다.
