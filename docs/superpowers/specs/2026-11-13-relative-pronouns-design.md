# 관계대명사 학습지와 PACE 문법 시험

## 승인된 요구사항
- 사용자 승인: 2026-11-13, 공부용 PDF와 PACE 시험을 함께 제작한다.
- 공부용 PDF의 원문을 개념 시험지에 그대로 옮기고 빈칸만 뚫는다. 문장, 예문, 해석, 항목 순서는 바꾸지 않는다.
- 가정법 PDF의 개념 → 형태 → 예문·해석 → 필수 표현 구성과 기존 시험 동작을 참고한다.
- 범위: who, which, that, 목적격·소유격, 생략, 전치사+관계대명사, 계속적 용법, what. 관계부사는 제외한다.
- 공부한 범위에서 실전 5지선다 10문제를 만들고 정답·해설을 제공한다.
- 가정법은 유지하고 관계대명사를 별도 단원으로 선택하여 배정한다. 기존 개념·실전 각각 80점 통과, 수동 개념 채점, 재시험 흐름을 유지한다.

## Approaches
- 선택: 한 데이터 원본과 공통 종이 렌더러에서 학습용 PDF와 개념 시험을 생성한다. 학습용은 빈칸 토큰의 정답을 표시하고 시험은 입력칸을 표시한다. 원문 불일치를 구조적으로 방지한다.
- 제외: PDF와 시험 내용을 각각 수작업으로 작성한다. 수정 시 서로 달라질 수 있어 사용자의 동일 원문 요구에 부적합하다.
- 제외: 종이 파일만 제공한다. 함께 만들어 달라는 PACE 연동 요구를 충족하지 못한다.

## 구현 판단과 경계
- 기존 단원 상수는 호환용으로 유지하고 단원 레지스트리를 추가한다. 단원 미지정은 기존 가정법으로 처리한다.
- 배정·재시험·결과는 단원별로 독립시킨다. 저장된 시험 원문 스냅샷은 수정하지 않는다.
- PDF는 루트의 `관계대명사_개념학습.pdf`로 제공하고, 배정 화면에서 다운로드할 수 있게 한다.
- 생성 스크립트는 기존 Playwright를 사용한다. 원문 PDF는 직접 읽기 도구가 지원하지 않아 텍스트 추출을 시도했으나 글꼴 매핑으로 깨지는 부분이 있다. 동일한 가정법 내용이 담긴 기존 `grammar_data.js`와 현재 화면 구성을 함께 참고한다.
- 인증·다른 시험·기존 사용자 파일은 변경하지 않으며 배포나 실제 학생 배정은 하지 않는다.
