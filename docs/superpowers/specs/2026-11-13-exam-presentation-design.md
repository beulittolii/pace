# 공통 시험 모드와 모션 시험지

## 의도와 승인된 디자인
2026-11-13 사용자와 여섯 차례 시안을 조정했고, 마지막 `exam-paper-options-v6.html`의 **A 시험지형**을 선택했다. 문법·복습에서 종이가 출력되는 느낌과 단정한 모의고사형 응시 화면을 제공하되 기존 모드를 완전히 보존한다.

참고 시안: `.superpowers/brainstorm/65197-1794531306/content/exam-paper-options-v6.html`. 시안의 중첩 로더·샘플 학생·가짜 저장 함수는 제품 코드로 옮기지 않는다.

## 사용자 요구사항
- 기존 모드는 현재 화면·문항 배치·입력 방식·제출 흐름을 그대로 유지한다. 새 CSS와 머리말은 기존 화면에 적용하지 않는다.
- 문법·복습 중 처음 시작하는 시험에서 `시험 모드를 선택하세요.`를 보여주고 `기존` / `모션 디자인` 중 선택한다. 다음부터는 선택한 모드로 시작하며 프로필 설정에서 변경할 수 있다.
- 선택한 모드는 문법·복습 공통이다. 계정에 저장하여 새로고침·다른 기기에서도 유지한다.
- 문법 상세 모달의 개념·실전 최신 결과는 성적표형 행으로 정리하고 분야 왼쪽 번호는 표시하지 않는다. 점수·통과/미달/대기 상태와 기존 답안/채점 동작을 유지한다.
- 공부용 PDF 다운로드는 파일 정보·내려받기 아이콘이 있는 버튼 모양의 링크로 제공한다.
- 모션 시작 시 전체 화면 하단의 고정 배출구에서 종이가 급지되고, 배출구를 통과하는 위치부터 내용이 인쇄된다. 출력된 실제 입력 DOM이 그대로 응시 화면이 된다.
- 모션 시험지는 부제목 `문법 테스트` / `복습 테스트`, 제목은 실제 문법 단원명 / `주간 단어 복습`으로 한다. 페이스·PACE ENGLISH·CONCEPT CHECK·교시·성명·단원·응시일 표 같은 부가 머리말은 넣지 않는다.
- 머리말·개념 소제목·번호·여백은 마지막 시안처럼 작고 단정하게 한다. 문제 번호는 본문과 같은 고딕 계열이다. 안내는 간결한 글머리표로 표시한다.
- 선지는 시험지형으로 한다. 줄별 색 면·테두리와 중복 라디오 표시 없이 ①~⑤를 표시하고 선택한 번호만 채워진 원으로 표시한다. 왼쪽 여백을 확보하고 키보드·터치 선택을 지원한다.
- 복습 스펠링은 뜻 박스와 넓은 한 줄 답안란을 분리한다. 정답 길이를 암시하는 글자 수 칸은 쓰지 않고, 답안 밑줄과 문항 구분선을 중복해서 표시하지 않는다.
- 모션 문법 실전은 실제 5지선다 10문항을 한 스크롤 페이지에 표시하고 마지막에서 일괄 제출한다. 데스크톱은 1~5번 / 6~10번 두 단, 모바일은 1~10번 한 단으로 읽는다. 기존 모드는 원래 한 문항씩 푸는 방식이다.
- 공부용 PDF와 개념 시험의 원문·예문·해석·순서 및 빈칸 ID는 유지한다. 시험지 장식은 공통 개념 본문 바깥에 둔다.

## Approaches
- 선택: 계정 공통 모드 선택기 + 독립된 모션 렌더러/스타일. 기존 렌더링 분기는 그대로 두고 모션일 때만 별도 표시한다. 원본 기존 화면과 비교·회귀 검증할 수 있다.
- 제외: 기존 응시 화면에 전역 스타일과 애니메이션을 덧씌우기. 기존 모드를 완전히 보존하라는 요구와 충돌한다.
- 제외: 완성된 종이 이미지를 슬라이드한 뒤 기존 화면으로 전환하기. 출력 느낌이 부족하고 같은 종이에서 응시한다는 요구를 충족하지 못한다.

## 구현 판단
- 학생 문서의 선택 필드 `examMode: 'classic' | 'motion'`를 사용한다. 없거나 알 수 없는 값이면 최초 선택이 필요하다. 로컬 저장소를 계정 설정의 유일한 원본으로 사용하지 않는다.
- 저장 성공 후 시험을 시작한다. 선택 취소·저장 실패·사용자 변경은 시험 시작 기록이나 문제를 만들지 않는다. 실패 시 선택을 보존하고 재시도할 수 있다.
- 응시 시작 때 모드를 세션에 고정한다. 프로필 변경은 다음 응시부터 적용하며 현재 답안·문제 순서를 재생성하지 않는다.
- 본인 계정과 연결된 학생 문서에만 모드를 저장한다. Firestore에서 학생의 수정 허용 필드를 target/examMode로 제한하고 examMode의 두 값만 허용한다. 다른 학생·권한·성적·계정 연결은 수정할 수 없다. 규칙 복사 페이지도 실제 규칙과 맞춘다.
- 첫 선택창과 프로필의 시험 모드 탭은 같은 저장 메서드를 사용한다. 프로필의 기존 목표·대학·비밀번호 탭 및 비동기 저장 잠금·포커스 복원을 보존한다.
- 애니메이션은 시작마다 한 번만 수행한다. 답안 입력·문항 선택·개념→실전 이동·결과 표시 때 재실행하지 않는다. 취소/종료/로그아웃/빠른 재시작에서는 프레임·타이머·inert·스크롤 잠금이 남지 않게 한다. 동작 줄이기 설정에서는 빠른 비연출 전환을 제공한다.
- 실제 SM신그래픽·Gulim 원본 폰트 및 웹 사용권은 확보되지 않았다. 설치된 해당 폰트를 우선 지정하고 시안에서 고지한 시스템 대체를 사용한다. 상용 폰트를 임의로 내려받거나 저장소에 포함하지 않는다.
- 단원 내용·합격 기준·수동 채점·응시 시각·재시험·복습 회차·성적 보존·시험 중 이탈 정책을 변경하지 않는다. 모션 문법 실전의 표시 방식만 한 페이지로 바뀐다.
- 현재 `pace` 작업 폴더에서 직접 구현하는 기존 사용자 선택을 따른다. 기존 사용자 파일을 보존하며 커밋·원격 푸시·서비스/보안 규칙 배포는 이번 구현에 포함하지 않는다.

## 검증과 경계
- 기존 모드의 DOM/시각 회귀, 실제 문법·복습 제출, 최초 선택·저장 실패·프로필 변경·새 세션, 권한 규칙, 모바일과 키보드를 검증한다.
- 현재 Java 런타임이 없다. Firestore 에뮬레이터 검증에 필요하면 승인된 임시 디렉터리의 휴대용 Java 21을 사용하고 시스템 설치·설정은 바꾸지 않는다. 규칙 테스트를 실행하지 못하면 미검증으로 분명히 보고한다.
- 배포 시에는 사이트뿐 아니라 새 examMode 저장 권한 규칙도 함께 적용해야 한다. 실제 운영 데이터로 시험을 배정하거나 답안을 제출하지 않는다.
