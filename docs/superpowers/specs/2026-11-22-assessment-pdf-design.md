# 수행평가 PDF 첨부

학생이 맥북의 PACE 수행평가 상세에서 PDF를 직접 첨부하고, 휴대폰에서도 같은 PACE 계정으로 로그인해 열 수 있게 한다. 수행평가당 PDF 1개, 최대 5 MiB(5,242,880바이트)로 시작하며 학생 본인이 교체하거나 삭제할 수 있다. 관리자용 첨부 보기, 공개 공유 및 다른 파일 형식은 범위 밖이다.

## Approaches

- Firebase Storage: 기존 인증과 통합하기 쉽지만 Blaze 결제 계정이 필요하다.
- Drive 링크: 결제 계정이 필요 없지만 학생이 파일을 별도로 올리고 링크를 붙여넣어야 한다.
- **선택: Supabase 무료 Storage.** PACE의 Firebase 로그인과 Firestore 학업 기록은 유지하고 PDF만 Supabase 비공개 버킷에 둔다. 학생은 Supabase에 따로 가입하지 않는다.

## 동작 및 접근 권한

기존 `auth-data.js` 브리지의 학생별 Firestore 수행평가 기록은 바꾸지 않는다. Supabase Edge Function은 PACE Firebase ID 토큰을 확인하고 같은 토큰으로 Firestore에서 계정-학생 연결 및 해당 수행평가의 존재를 확인한다. 확인된 UID·학생 ID·수행평가 ID로만 파일 위치를 계산한다. 브라우저에 Supabase 관리자 키를 공개하거나 공개 다운로드 URL을 발급하지 않는다. 서버와 버킷에서 PDF 및 크기 제한을 적용한다.

상세 화면은 `자료 PDF`에 `PDF 첨부` 또는 `파일 열기 · 교체 · 삭제`를 표시한다. 컴퓨터에서는 파일 선택 버튼 외에 `여기에 PDF를 드래그해 첨부` 영역을 표시한다. 휴대폰에서는 드롭 영역 없이 파일 선택 버튼을 사용한다. 드롭은 파일 1개만 받으며 파일 선택과 같은 검사 및 업로드 흐름을 사용한다. 기존 파일이 있다면 교체 확인을 받는다. 드롭한 파일을 브라우저가 현재 탭에서 열어버리지 않게 한다.

저장소 오류나 일시정지 시 첨부 영역만 오류를 표시하고 기존 수행평가 저장·조회는 계속 가능하다. 파일 삭제는 첨부 UI의 명시적 동작이다. 수행평가 자체를 삭제하면 파일 접근은 차단되며, 남은 원본은 운영자가 정리할 수 있도록 문서화한다.
