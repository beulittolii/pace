# PACE

영어과외 학생 6명의 테스트 일정, 본시험/재시험 통과 여부, 커트라인 및 상세 피드백을 체계적으로 관리할 수 있는 맞춤형 웹 애플리케이션입니다.

---

## 📌 주요 기능 안내

### 1. 초대 코드 회원가입과 로그인
- 환영 → 계정 설정 → 6자리 초대 코드 → 완료 순서로 가입합니다. 단계 전환과 완료 애니메이션은 기기 설정과 관계없이 실행됩니다.
- 관리자가 발급한 대문자·숫자 혼합 6자리 코드는 먼저 가입을 완료한 한 계정만 사용할 수 있습니다.
- 아이디·비밀번호로 로그인하며, ‘자동 로그인’을 선택하면 브라우저 재시작 후에도 인증 상태를 유지합니다.
- 기존 학생 기록은 가입 후 관리자가 연결합니다. Firebase 무료 인증 설정·데이터 이전·규칙 배포는 [운영 적용 안내](AUTH_SETUP.md)를 따릅니다.

### 2. 학생별 인터랙티브 캘린더 & 상세 정보 뷰
- **월간 캘린더**: 월별 시험 일정과 재시험 일정을 달력에서 한눈에 확인.
- **색상별 상태 배지**:
  - 🟢 **초록색**: 본시험 통과 또는 재시험 합격 (PASS)
  - 🟡 **주황색**: 재시험 대기 (RETEST PENDING)
  - 🔴 **빨간색**: 불합격 (FAIL)
  - 🔵 **파란색**: 시험 예정 (SCHEDULED)
- **시험 상세 모달 (일정 클릭 시)**:
  - 📅 시험 일시 및 D-Day
  - 🎯 시험 범위 및 상세 안내
  - 📊 커트라인(기준점수) 및 본인 획득 점수
  - 🏆 1차 본시험 통과 여부
  - 🔄 재시험 통과 여부 및 재시험 일자
  - 💬 선생님의 1:1 맞춤 피드백 & 복습 가이드
- **리스트형 뷰 탭**: 캘린더 외에 [전체 / 예정 / 통과 / 재시험] 필터로 모아보기 지원.

### 3. 선생님 관리자 모드 (`Admin`)
- **관리자 로그인**: Firebase에 별도로 준비한 관리자 계정으로 로그인합니다. 공용·고정 비밀번호는 사용하지 않습니다.
- **시험 일정 및 성적 관리**:
  - 새 시험 일정 등록 및 수정 / 삭제
  - 원클릭 상태 변경 버튼 (본시험 통과/불합격/대기, 재시험 통과/탈락/대기/해당없음)
  - 커트라인, 학생 점수, 시험 범위, 피드백 코멘트 관리
- **전체 6명 학생 종합 현황판**: 6명 학생의 통과율, 다음 시험, 재시험 건수를 매트릭스로 비교.
- **학생 프로필 정보 수정**: 학생 이름 및 학습 목표를 자유롭게 수정 가능.
- **데이터 백업 및 복원**:
  - `JSON 다운로드`: 현재 데이터를 파일로 백업
  - `JSON 가져오기`: 백업 파일로 데이터 즉시 복원
  - `기본 샘플 데이터 리셋`: 초기 테스트 데이터로 초기화

### 4. 문법 테스트

- 시험 관리의 `문법 테스트 추가`에서 학생과 응시 일정을 지정합니다. 가정법 최초 배정은 개념과 실전을 함께 출제합니다.
- 개념은 원문을 옮긴 빈칸 시험지입니다. 빈칸을 남기고 넘어가면 미입력 개수를 확인하며, 실전 진입 후 개념은 수정할 수 없습니다.
- 실전은 5지선다 10문제이며, 마지막 문항에서 제출할 수 있으며, 미응답 문항이 있으면 개수를 확인한 뒤 제출합니다. 제출 즉시 점수와 80점 통과 여부가 표시됩니다.
- 개념은 `결과 / 채점`에서 일치 답안은 자동 정답 처리하고 다른 답안만 검토합니다. 미입력은 오답이며 전체 빈칸 수에 포함합니다. 개념과 실전은 각각 80점 이상 통과입니다.
- 재시험은 선생님이 미달한 영역만 새로 배정합니다. 기존 성적과 응시 이력은 유지합니다.
- 재시험으로 미달 영역을 모두 통과하면 본시험 일정도 기존 문법 테스트 아이콘을 유지한 채 초록색 완료 상태로 표시합니다. 관리자 상태에는 `재시험 통과`를 표시하며, 본시험 점수와 상세 성적은 바꾸지 않습니다. 채점 대기는 완료로 처리하지 않고, 통과한 재시험을 삭제하면 이전 상태로 돌아갑니다.
- 응시 중 임시 저장·이어 풀기를 제공하지 않습니다. 개념 제출과 최종 제출 때 답안을 저장하며, 저장 실패 시 같은 화면에서 다시 제출할 수 있습니다.
- 응시 시작부터 최종 제출까지 돌아가기·로고·로그아웃 등 앱 내 이동과 브라우저 뒤로가기를 차단합니다. 새로고침·탭 닫기에는 브라우저 기본 이탈 경고를 표시합니다. 브라우저가 강제 종료를 허용하면 앱에서 이를 완전히 막을 수는 없습니다.

### 5. 토요일 주간 단어 복습

- 단어 시험 배정 시 객관식·스펠링·통합의 출제 문항 수에 `0`을 입력하면 해당 유형은 응시·선행 단계·합격 조건에서 제외됩니다. 빈칸은 기존 40문항이며, 적어도 한 유형은 출제해야 합니다. 수정할 때도 제외 설정이 유지됩니다.
- 주간 복습은 실제 출제한 유형의 기록만 사용합니다. 객관식 기록은 객관식으로, 스펠링 기록은 스펠링으로 복습하며, 통합 기록은 기존처럼 오답 성격에 따라 두 복습 유형을 사용합니다. 정답 단어도 그 단어가 실제 출제된 분야 안에서만 선정하며, 이미 확정·제출된 복습지는 변경하지 않습니다.
- 해당 주에 단어 시험이 배정되면 토요일 `주간 복습`이 잠긴 상태로 미리 생성됩니다. 월~금 매일 배정된 단어 시험을 모두 최종 통과하면 문항이 확정되고 응시 잠금이 해제됩니다. 통합 시험은 관리자 채점까지 완료해야 합니다. 접속·응시·채점 후 확인하며 서버 예약 작업은 사용하지 않습니다.
- 관리자 주간 복습 상세 모달에서 제외할 요일을 선택하고 저장할 수 있습니다. 제외 요일은 응시 조건과 출제 범위에서 빠지고, 완료 일수의 분모도 남은 요일 수로 바뀝니다. 전체 제외 시 해당 주 복습을 생략합니다. 일반 복습은 첫 회차 제출 후 성적 보존을 위해 설정을 유지합니다. 체험용 복습은 제출 후에도 문항·성적을 보존한 채 요일 선택을 확인할 수 있습니다.
- 한국 시간 토요일 00:00부터 응시하며, 늦게 평일 시험을 끝내도 해당 주차 복습을 계속할 수 있습니다.
- 해당 주 오답 최대 30개와 한 번도 틀리지 않은 정답 단어 최대 10개를 출제합니다. 이전 재시험 오답도 포함하며 오답이 없으면 시험 없이 복습 완료로 표시합니다. 원본과 정확히 연결할 수 없는 기록은 출제하지 않고 관리자에게 자료 확인 상태를 표시합니다.
- 뜻 오답은 5지선다, 스펠링 오답은 영어 입력입니다. 모든 문항을 한 페이지에서 풀고 한 번에 제출합니다. 회차 제출 후 오답만 반복하며 모두 해결하면 완료됩니다. 첫 점수는 유지하고 커트라인·제한시간·재응시 대기시간은 적용하지 않습니다.
- 중도 이탈에 불이익이 없으며 마지막 제출 회차부터 이어갑니다. 작성 중인 미제출 답안은 저장하지 않습니다.
- 관리자는 시험 목록 또는 복습 상세에서 주간 복습과 해당 응시 기록을 삭제할 수 있습니다. 삭제한 복습은 같은 학생·주차에 다시 자동 생성되지 않으며, 원래 단어 시험과 성적은 유지합니다.
- 생성 문항·원본 연결은 시험 문서에 고정하고 진행 기록은 기존 권한이 적용되는 시험 문서의 `weeklyReviewResult`에 별도 보관합니다. JSON 백업·복원에 포함되며 기존 단어 성적은 변경하지 않습니다.

주간 복습 로직 테스트: `node --test tests/weekly-review.test.cjs`

주간 복습 브라우저 테스트: `node tests/weekly-review-browser.cjs` (Playwright 및 Chrome 필요, `TAILWIND_SCRIPT_PATH`로 로컬 Tailwind 스크립트 지정 가능). 실제 Firebase 대신 격리된 트랜잭션 저장소를 사용합니다.

문법 로직 테스트: `node --test tests/grammar.test.cjs`

브라우저 테스트: Playwright가 설치된 환경에서 `node tests/grammar-browser.cjs`. 실제 Firebase에 연결하지 않는 격리된 테스트입니다. 필요하면 `NODE_PATH`와 `CHROME_PATH`로 Playwright 설치 위치와 Chrome 실행 파일을 지정할 수 있습니다.

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 정적 파일을 HTTP(S) 서버에서 제공하면 됩니다. 인증 운영 설정은 `AUTH_SETUP.md`를 참고하세요.

- **로컬 실행**: `python3 -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다. 실제 계정 사용에는 Firebase 설정이 필요합니다.
- **데이터 저장**: Firebase Cloud Firestore에 자동 저장되어 기기와 브라우저가 달라도 같은 데이터를 실시간으로 확인할 수 있습니다.

DB 잔여 기록 점검: `python3 scripts/cleanup_database.py`. 삭제된 학생의 기록·단어장 권한과 삭제된 시험의 응시 결과를 점검합니다. `--apply`는 원본 백업 후 변경 시각 조건을 붙인 단일 커밋으로 반영합니다. 기본 백업 위치는 `/private/tmp/english-mastery-cleanup`이며 `--backup-dir`로 변경할 수 있습니다. 계정 비밀번호가 포함될 수 있으므로 백업을 공개 저장소에 올리지 마세요.

삭제 경로 회귀 테스트: `node --test tests/cleanup.test.cjs`.

### 자동 버전 증가

이 저장소에서는 커밋마다 푸터 버전의 패치 번호를 1씩 올립니다(예: v1.0.6 → v1.0.7). `git config core.hooksPath .githooks`를 한 번 실행하면 이후 커밋에 자동 적용됩니다. 버전은 직전 커밋을 기준으로 계산하므로 커밋 실패 후 재시도해도 중복 증가하지 않습니다. 직전 커밋보다 높은 버전을 직접 지정한 경우 해당 버전을 유지합니다(예: v2.0.0). 과거 업데이트 안내에 적힌 버전은 유지합니다. `index.html`에 스테이징하지 않은 수정이 있으면 먼저 정리한 뒤 커밋해야 합니다.

### PACE 화면과 학습 기록

로그인·학생 홈·성적 화면은 PACE 심볼과 딥 틸 디자인을 사용합니다. 홈의 복습 버튼은 선택한 학생의 실제 주간복습에 연결되며, 미배정 상태에서는 비활성화됩니다. 단어 학습 기록은 시험 유형별 최신 채점 결과를 집계하고 채점 대기 결과는 제외합니다. 기존 학생 ID와 성적은 유지하며, 로그인은 Firebase Authentication으로 전환합니다.

화면 검증: `node tests/pace-browser.cjs` (Playwright와 Chrome 필요). 학생별 기록, 평균 점수, 채점 대기·빈 상태, 권한, 모바일 레이아웃을 운영 Firebase 없이 검사합니다.
